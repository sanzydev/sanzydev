### Core Profile

Founder dan lead developer di **MythicCraft Studio**. Mengembangkan mekanik real-time dan replikasi state jaringan berbasis Luau di platform Roblox, merakit dashboard serta pipeline terdistribusi menggunakan Next.js/React, dan mengeksplorasi automasi bot headless hingga runtime Native Android via Kotlin.
